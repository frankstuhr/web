# web

Hello-World-Seite mit wechselnden Bildern aus dem Kraichgau.
Veröffentlicht über GitHub Pages: https://frankstuhr.github.io/web/

## Bedienung

- Bilder wechseln automatisch alle 7 Sekunden
- **Am Handy:** nach links/rechts wischen
- **Am Rechner:** Pfeiltasten ← → oder auf die Punkte klicken

## Bildnachweise

(Wikimedia bittet darum, Bilder nicht dauerhaft von deren Servern einzubinden).

## Lokale Entwicklung

```bash
python3 -m http.server 8000
```

Dann http://localhost:8000 öffnen. Das Repo liegt lokal unter
`Repos/web` (neben `Claude Input` und `OBSIDIAN VAULT`).
